# EXILE Recap

<p align="center">

</p>

**Match results, made clear.**


A lightweight LabyMod 4 addon that displays match results from the EXILE Minecraft network in a clean, configurable HUD.

The game server is responsible for deciding the winner, computing statistics, and awarding Gold. The addon only displays the result; it does not modify game logic.
